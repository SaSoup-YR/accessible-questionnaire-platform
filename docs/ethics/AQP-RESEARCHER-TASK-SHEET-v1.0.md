# Researcher Task Sheet

**Activity:** Observed Evaluation of Questionnaire Study-Setup Workflows
**Status:** Protocol draft only; use only after written amendment approval.
**Version:** 1.1, 10 August 2026

We are testing the setup tools, not you. Work as you normally would. You may speak
aloud, but you do not have to. You may ask the observer to repeat the task. Do not
use real participant data.

## Required end state for each setup tool

Create a working participant link with:

- study title: `Researcher setup comparison`;
- task: `Use the test product, then answer SUS`;
- participant code: `RESEARCHER-DEMO`;
- the supplied 10-item SUS questionnaire in the supplied order;
- response values 1–5 and the supplied endpoint labels;
- every question required and one question per screen;
- score name `SUS score`; and
- a collection/export route that can return all 10 answers, the participant code
  and the score after a synthetic response.

Tell the observer when you believe the setup is complete. The maximum active time
is 20 minutes per tool. Do not answer SUS yourself. After you declare completion,
the timer stops; the observer will test the link and export with fixed synthetic
answers. Observer verification is not part of your task time.

## Condition A — AQP

Start from the AQP researcher page supplied by the observer. Use the ready-made SUS
route. The required result-collection end state is **This browser only**. Produce
the required end state above and a participant-specific link that opens in a new
tab in the same browser.

## Condition Q — Qualtrics

Start from the fresh prepared Qualtrics template supplied by the observer. The
template already contains SUS. Set the project/visible first-page title and task,
publish an anonymous participant link, and use the supplied `participant_code`
route so the response row will store `RESEARCHER-DEMO`. Produce the same required
end state above.

The observer will tell you which condition to do first. Do not use another template
or type a different questionnaire.

## Checking task

After both setup tasks, compare the supplied source sheet with the supplied imported
definition. Check the question wording/order, answer labels, stored values and
scoring. Tell the observer every difference that should be resolved before release.
Do not edit either file. Maximum time: 8 minutes.
