# Archived AQP Records

This directory contains superseded but still traceable public records. They are kept for provenance and are not current installation, evaluation, or release instructions.

- `legacy/` contains older release gates, migration notes, pre-final evidence freezes, and earlier evaluation or supervisor-response documents.
- `evidence/` contains intermediate repair plans, candidate descriptions, and failed or superseded experimental routes.

Current software and evidence guidance starts at the repository `README.md`, `TESTING.md`, `EVIDENCE-INDEX.md`, `RELEASE-NOTES.md`, and `docs/evidence/FINAL-PROTOTYPE-FREEZE-2026-08-22.md`.

Archiving a file does not change its historical result. Failed observations and superseded implementations remain available and are not converted into final Pass claims.
