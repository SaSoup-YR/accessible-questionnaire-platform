# Planned Study Not Executed

The repository previously contained public drafts for a possible observed researcher study, including recruitment, consent, task, coding, risk, and post-condition materials.

That study was **not executed as evidence for this dissertation release**. No participant recruitment, consent, session recording, demographic collection, or participant-result analysis is represented by AQP `v0.8.0` or the `v0.8.1` curation release.

The public evidence consists of:

- deterministic source and component tests;
- rendered-browser and cross-browser mechanism tests;
- a configuration-bounded manual audit using the named assistive technologies;
- targeted post-fix retesting and residual-failure records;
- synthetic local and Qualtrics deployment checks.

The planning documents have been moved to the private project archive to prevent them from being confused with an approved or completed participant study. Any future human study requires the applicable written ethics approval, approved participant materials, data-management arrangements, and a new evidence record.
