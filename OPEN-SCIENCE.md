# Open Science Material Inventory

This file separates material that is currently public, material that will be included in the dissertation archive, and material that is not available because it does not exist or should not be public.

## Public in This Repository

- TypeScript and JavaScript source code;
- the committed dependency lockfile;
- unit, component, rendered-browser, and cross-browser tests;
- synthetic import fixtures;
- distributable questionnaire definitions and JSON Schema;
- current Qualtrics integration materials;
- the frozen manual assistive-technology audit;
- targeted post-fix and residual-failure evidence;
- release, deployment, and public-page provenance;
- build, testing, citation, licence, and third-party information.

## Dissertation Archive Material

After the `v0.8.1` repository curation and the final literature verification are complete, the archival deposit will include:

- the exact released source snapshot;
- the final evidence index and current evidence records;
- the literature search, screening, study-family, and author-verification tables used in the dissertation;
- the final core-literature claim matrix;
- any analysis scripts used to generate reported numbers, tables, or figures;
- a material manifest that identifies the corresponding software tag and dissertation version.

The intended archival service is Zenodo or OSF because it can preserve a fixed version and issue a DOI. The DOI is not added before the final deposit exists.

## Data Types Not Available

| Data type | Status and reason |
| --- | --- |
| Participant data | None were collected for the released dissertation evidence. The proposed observed study was not executed. |
| Signed consent forms | None exist because no participant study was run. |
| Session recordings | None exist for a participant study. Manual developer/auditor screenshots are represented by redacted observations or hashes where public release could expose account or device information. |
| Private sealed test discrepancy | Not part of the released technical evaluation and not public. |
| Real Qualtrics participant responses | None are included. Only synthetic fault and deployment checks are reported. |
| Licensed questionnaire material beyond the distributable files | Controlled by the relevant instrument or source rights and not redistributed without permission. |

## Anonymous Submission

The public repository contains author identity in its account name, citation metadata, and history. An anonymous dissertation submission must therefore use the anonymous link required by the assessment procedure rather than linking directly to this named repository. The public repository itself is not altered to create a misleading anonymous history.
